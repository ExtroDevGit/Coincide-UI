# Chams

Controls highlight-style rendering through walls.

## Main keys
- `Chams.Enabled`
- `Chams.Type` (`Highlight`, `Adornment`, `MeshChams`)

## Type blocks
- `Chams.Highlight.*` — fill/outline colors, transparency, visibility mode
- `Chams.Adornment.*` — color set, transparency, top-most mode, visibility check
- `Chams.MeshChams.*` — shell + highlight appearance for humanoid targets
