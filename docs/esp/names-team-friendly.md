# Names, Team, and Friendly Indicators

Configures player name text and side indicators.

## Name keys
- `Names`
- `TextSize`
- `TextColor`
- `TextOutline`
- `TextOutlineStyle`
- `TextGap`
- `Font`

## Team indicator
- `TeamIndicator.Enabled`
- `TeamIndicator.Position`
- `TeamIndicator.UseTeamColor`
- `TeamIndicator.Color`
- `TeamIndicator.Compact`
- `TeamIndicator.TextSize`

## Friendly indicator
- `FriendlyIndicator.Enabled`
- `FriendlyIndicator.Position`
- `FriendlyIndicator.CheckTeam`
- `FriendlyIndicator.CheckFriends`
- `FriendlyIndicator.Text`
- `FriendlyIndicator.Color`
