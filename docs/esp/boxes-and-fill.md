# Boxes and Fill

Controls 2D box rendering around targets.

## Box keys
- `Boxes`
- `BoxType` (`Normal`, `Corner`, `Circle`)
- `BoxColor`
- `BoxThickness`
- `Outlines.Style`, `Outlines.Color`, `Outlines.Thickness`

## Fill keys
- `BoxFill.Enabled`
- `BoxFill.Color`
- `BoxFill.Transparency`
- `BoxFill.Gradient.*` (enabled, colors, rotation, animation, speed, direction, alpha stops)

## Glow
- `Glow`
- `GlowColor`
- `GlowTransparency`
- `GlowGradient`
