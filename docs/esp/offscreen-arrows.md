# Off-Screen Arrows

Renders directional markers for targets outside view.

## Main keys
- `OffScreenArrows.Enabled`
- `OffScreenArrows.Size`
- `OffScreenArrows.Color`
- `OffScreenArrows.OrbitRadius`
- `OffScreenArrows.ArrowMode`
- `OffScreenArrows.Outline`
- `OffScreenArrows.OutlineColor`

## Optional text blocks
- `OffScreenArrows.Names.*`
- `OffScreenArrows.Distance.*`
