# Distance and Weapon Text

Shows distance and current weapon labels.

## Distance keys
- `Distance.Enabled`
- `Distance.Unit`
- `Distance.StudsPerMeter`
- `Distance.Ending`
- `Distance.Gap`
- `Distance.OutlineStyle`
- `Distance.Font`
- `Distance.TextSize`
- `Distance.Color`

## Weapon keys
- `Weapon.Enabled`
- `Weapon.Gap`
- `Weapon.OutlineStyle`
- `Weapon.Font`
- `Weapon.TextSize`
- `Weapon.Color`
- `Weapon.InventoryPath`
- `Weapon.UseToolFallback`
