# Window

Creates the main draggable/resizable UI container.

## Entry point
- `Library:Window({ Width, Height, Title })`

## Key capabilities
- Hosts tabs and sections
- Can be shown/hidden or destroyed
- Supports synchronization with side panels (preview/settings/player list)

## Related methods
- `Window:Tab({ Name })`
- `Window:SetVisible(boolean)`
- `Window:Toggle()`
- `Window:Destroy()`
