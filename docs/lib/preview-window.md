# Preview Window

Standalone panel for previewing and tuning ESP visuals.

## Entry point
- `Library:PreviewWindow({ Title, Width, Height })`

## Position/sync helpers
- `PositionNextTo(window)`
- `SyncWithWindow(window)`

## Proxy methods
- `Get(key)`
- `Set(key, value, alpha?)`
- `Update()`
- `SetText(which, text)`
- `ViewModel(model)`
- `Refresh()`
- `SyncFromESP(config)`
- `Destroy()`
